geometry_01.math — Pythagorean Theorem

የፓይታጎረስ ቲዎሬም The Pythagorean Theorem Il Teorema di Pitagora

በቀኝ ማዕዘን ሶስት ማዕዘን ውስጥ፣ ሀይፖቴኑዝ ካሬ ሌሎቹ ሁለት ጎኖች ካሬ ድምር ጋር እኩል ነው። In any right-angled triangle, the square of the hypotenuse equals the sum of the squares of the other two sides. In qualsiasi triangolo rettangolo, il quadrato dell'ipotenusa è uguale alla somma dei quadrati degli altri due lati.

c = ሀይፖቴኑዝ (ረጅሙ ጎን)፣ a እና b ሌሎቹ ጎኖች ናቸው። Where c is the hypotenuse (longest side), and a, b are the other sides. Dove c è l'ipotenusa (lato più lungo), a e b gli altri lati.

a² + b² = c²
Pythagorean Theorem
3² + 4² = 5²
9 + 16 = 25 ✓

6² + 8² = c²
36 + 64 = 100
c = 10 ✓
python_01.py — Variables & Loops

Python: ተለዋዋጮች እና ሎፕ Python: Variables & Loops Python: Variabili e Cicli

ተለዋዋጭ (variable) ዳታን ለማስቀመጥ ያገለግላል። ሎፕ (loop) ኮዱን ደጋግሞ ያሄዳል። A variable stores data. A loop repeats code multiple times automatically. Una variabile memorizza dati. Un ciclo ripete il codice automaticamente.

Python ለጀማሪዎች በጣም ቀላል ቋንቋ ነው! Python is the #1 beginner-friendly language! Python è il linguaggio più adatto ai principianti!
